# Part 1 starter project

This project contains starter files for the five JavaScript exercises in Part 1 and example tests for Exercises 1 and 2.

## Setup

```shell
pnpm install
pnpm test
```

The supplied tests are expected to fail until Exercises 1 and 2 are implemented. Students must add tests for Exercises 3, 4, and 5, as well as additional tests for Exercises 1 and 2.
